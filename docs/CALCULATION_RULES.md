# Nesting1D 計算ルール

## 1. 適用範囲
初期版の純粋な計算ロジックへ適用する。数学的完全最適は保証せず、同じ入力・アプリバージョン・探索方式では同じ結果を返す。

## 2. 正規化と入力範囲
- 単位はmm、数値は整数。同じ部材寸法の行は本数を合算し、寸法降順へ正規化する。
- 新品母材長は1種類で、在庫モードの保有材と追加購入材に共用する。既存残材は寸法別入力可。

| 項目 | 最小 | 最大 |
|---|---:|---:|
| 新品母材・既存残材・部材寸法 | 1 | 1,000,000 |
| 鋸刃厚・左端捨て切り | 0 | 10,000 |
| 1行の本数 | 1 | 100,000 |
| 必要部材行数 | 1 | 1,000 |
| 既存残材行数 | 0 | 1,000 |
| 合計必要本数 | 1 | 1,000,000 |

通常利用目標は合計1,000本程度。文字、小数、範囲・行数・合計本数超過は入力エラー。

## 3. 長さの式
母材長 `S`、捨て切り `T`、鋸刃厚 `K`、部材長 `L1...Ln` とする。

```text
左端処理 = T + K
部材1本 = Li + K
合計使用長 = T + K + Σ(Li + K)
残り長 = S - 合計使用長
```

新品母材・既存残材とも左端処理を1回行う。左から右へ切り、右端捨て切りなし。`残り長 >= 0` の配置だけ有効。鋸刃厚0でも同じ式。

## 4. 使用可否
- `T + K + 部材寸法 + K > S` ならその母材から切り出せない。
- 新品母材からも切れない必要部材は計算不能エラー。
- 正しい数値の既存残材から今回の部材を1本も切れない場合は、エラーでなく理由付き未使用在庫。

## 5. 残材・廃棄材
境界は `50 + K`。残りが境界以下なら廃棄材、超えれば残材。境界値そのものは廃棄材。今回利用不能でも境界超過なら残材。

## 6. パターン
- 部材寸法と寸法別本数が同じなら配置順によらず同一。
- `(部材寸法, 本数)` を寸法降順に並べた列をパターンキーとする。
- 同寸法を連続させ、表示・切断手順は寸法降順。同一パターンを集約し使用回数を返す。

## 7. 候補評価
### 候補生成
- 必要母材算出モードは切断順2戦略から2候補を生成する。
- 在庫モードは切断順2戦略と既存残材の使用・不使用から4候補を生成する。
- 全候補を`SelectionCandidate`へ変換し、engineから`select_candidate()`へ渡す。旧比較で事前削減しない。

### 共通選別順位
(1)完全充足、(2)追加購入新品母材数、(3)廃棄材総量と許容値、(4)残材総量と独立した許容値、(5)残材本数、(6)パターン数、(7)寸法変更回数、(8)候補内容から生成した安定キーの順に比較する。すべて少ない値を優先し、許容値と同じ差は範囲内とする。既定許容値は両方0mmで、加重点評価は使用しない。

## 8. 集計と再現性
- 寸法別必要数・完成数・不足数、在庫のみの完成数、追加購入後の最終完成数を区別する。
- 使用材、未使用在庫、新規残材、廃棄材を区別する。割合の丸めは表示層で行う。
- 安定キーは母材順とcuts順を保持し、未使用材料の登録順だけを正規化する。理由コードは含めず、主要評価同値時だけ使用する。
- 候補生成順、辞書・集合の偶然の順序へ依存しない。パターン番号は確定順に `P01` から付ける。
- 未使用理由は、需要充足済み、物理的切出不能、使用可能だが候補選別で不使用、の順に同じ判定を適用する。
